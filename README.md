# Виртуальный счёт: программа-сторож

Учебный эксперимент Олега и Claude: торговля **виртуальными** деньгами по заранее записанным правилам. Настоящих денег, бирж, кошельков и ключей здесь нет. Программа только читает публичные цены и записывает виртуальные сделки в файл.

## Как это работает

- **Программа-сторож** (`watcher/watch.py`) запускается на GitHub каждые 5–10 минут. Она берёт свежие цены, сразу продаёт по стопу, подтягивает следящий стоп и покупает по правилам.
- **Claude** 2 раза в день читает этот проект: проверяет новости по купленным монетам, пишет дневник решений и переносит данные на страницу «Виртуальный счёт Олега». По воскресеньям подводит итоги и может поменять одно правило.

## Счета (по $10 000 виртуальных денег)

| Счёт | Что делает |
|---|---|
| `trend` | BTC, ETH, SOL: покупает, только когда цена выше средней за 20 дней и средняя растёт |
| `hype` | Монеты из топ-200, которые взлетели за сутки на 15%+, со стопом и следящим стопом |
| `stocks` | 15 крупных акций США по тому же трендовому правилу, только пока открыта биржа |

Для сравнения ведутся два счёта «купил и держу»: BTC, ETH, SOL поровну и фонд SPY.

## Файлы

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `state/rules.json` | Claude | Правила: все числа, по которым торгует сторож |
| `state/commands.json` | Claude | Решения Claude, например «продать монету после плохих новостей» |
| `state/state.json` | сторож | Деньги, позиции, сделки, события, стоимость счетов по дням |

Остановить торговлю: поставить `"paused": true` в `state/rules.json`.

Источники цен: Kraken (BTC, ETH, SOL), CoinLore (остальные монеты), Yahoo Finance (акции).

Это эксперимент, а не финансовый совет.
